# Getting help

- **A mistake or a gap in the docs:** open an [issue](https://github.com/hostrepute/reputecastdocs/issues/new/choose)
  with the page's address, or fix it in a pull request ([CONTRIBUTING.md](CONTRIBUTING.md)). Every page also has an
  **Edit page** link at the bottom.
- **Questions about installing or using ReputeCast:** ask in ReputeCast's
  [Discussions](https://github.com/hostrepute/reputecast/discussions). Search first; someone may have asked already.
- **Bugs in ReputeCast:** open an [issue](https://github.com/hostrepute/reputecast/issues/new/choose) in the
  ReputeCast repository.
- **Security problems:** follow [SECURITY.md](SECURITY.md) instead of opening an issue.
