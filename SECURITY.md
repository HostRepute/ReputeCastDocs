# Security policy

This repository holds the ReputeCast documentation site, [docs.reputecast.com](https://docs.reputecast.com).

## A vulnerability in ReputeCast

Report it privately to the ReputeCast project, as its
[security policy](https://github.com/hostrepute/reputecast/blob/main/SECURITY.md) describes. Please don't report it
here.

## A vulnerability in the documentation site

For example script injection on a page, a secret committed to this repository, or a vulnerable dependency the built
site serves. Please don't open a public issue, discussion or pull request for it.

Report it privately through GitHub instead:
[report a vulnerability](https://github.com/hostrepute/reputecastdocs/security/advisories/new) (the repository's
**Security** tab › **Report a vulnerability**). Only the maintainers can see the report.

Please include:

- the page URL or the file;
- how to reproduce it;
- what an attacker could do with it.

We'll confirm we received the report, keep you updated while we fix it, and tell you when the fix is live. Tell us if
you'd like to be credited.
