Find, filter and change your [contacts](/reference/glossary/#contact) in
<UiPath path="nav.audience > audience.tabContacts" />, and open any profile to see its fields, consent per list and
every email it was sent. This page covers how to manage email subscribers one at a time and in bulk; to bring many
in at once, [import them](/audience/import/).

## Before you begin

Permission keys say `subscribers`; the app says contacts.

<TableScroll label="Permissions for contact actions">

| Action | Permission | Built-in roles |
| --- | --- | --- |
| See contacts, profiles and activity | `subscribers:view` | Owner, Admin, Editor, Viewer |
| Add a contact | `subscribers:create` | Owner, Admin, Editor |
| Add to a list, add a tag, resend opt-in, suppress, edit fields | `subscribers:edit` | Owner, Admin, Editor |
| Export a CSV or a contact's data | `subscribers:export` (sensitive) | Owner, Admin |
| Erase contacts | `subscribers:delete` (sensitive) | Owner, Admin |

</TableScroll>

A role limited to some lists sees only the contacts on those lists. See
[roles and permissions](/team/roles-and-permissions/).

## Find contacts

<Screenshot
  id="contacts"
  alt="Contacts with saved views as chips above the filters, then a table showing each contact's lists, tier, score, consent and mailbox provider."
/>

<Steps>

1. Go to <UiPath path="nav.audience > audience.tabContacts" />.

2. Type in **Search email, name or tag**. Search matches part of an email address or a name, or a tag exactly
   (tags are stored in lower case).

3. Narrow the table with the filters: **List**, **Tier** ([engagement tier](/audience/list-health/)), score band,
   **Mailbox provider**, **Consent**, language and address check. <UiPath path="audience.contacts.moreFilters" />
   adds **Source**, **Tag**, **Joined after**, **Segment**, growth source and UTM values, and a score range. Filters
   for paid status, purchases, phone and SMS consent, push and WhatsApp appear once those features are in use.

4. To keep the filters, select <UiPath path="audience.contacts.saveCurrent" />, name the view and select
   **Save view**. Tick **Only for me** to keep it private; shared views show for everyone in the workspace. Each
   view's count updates as contacts change.

</Steps>

The table is sorted by last activity; select the **Score** header to sort by score instead. **Last open** shows
"never", a date, or "_date_ · machine" when the last open came from a mail client that loads images by itself, such
as Apple Mail Privacy Protection. A red **Suppressed** badge in **Consent** means the address is on the
[suppression list](/audience/suppressions/).

On a phone, the saved views and the filters stack above the table, and the app's sections move to a bar at the
bottom of the screen.

## Add a contact

<Steps>

1. Select <UiPath path="audience.contacts.addContact" />.

2. Enter the email, optionally first and last name and tags, and tick at least one list.

3. Under **Consent**, choose:

   - <UiPath path="audience.contacts.sendConfirmation" /> (default): double opt-in. The contact stays pending until
     they click the link, sent through the System stream.
   - <UiPath path="audience.contacts.alreadyAgreed" />: single opt-in. They are subscribed at once. Use this only when
     you have their consent on record.

4. Select **Add contact**. The contact's source shows as "Added by the team", with your name in the consent history.

</Steps>

An address on the suppression list, or one that is already a contact, is refused. See
[Lists, consent and double opt-in](/audience/lists-and-consent/) for how each consent status works.

## Change many contacts at once

Tick contacts on the current page (up to 100), then pick a bulk action. The selection clears when you change the
page, a filter or the page size.

<TableScroll label="Bulk actions">

| Action | What it does |
| --- | --- |
| <UiPath path="audience.contacts.addToList" /> | Subscribes them to a list at once. Suppressed addresses are refused. |
| <UiPath path="audience.contacts.addTag" /> | Adds a tag (lower case, up to 60 characters). |
| <UiPath path="audience.contacts.resendOptin" /> | Sends a confirmation email through the System stream, up to 5,000 contacts. |
| <UiPath path="audience.contacts.exportCsv" /> | Downloads the selected contacts as CSV. Every export is in the audit log. |
| <UiPath path="audience.contacts.suppress" /> | Adds the addresses to the suppression list for all mail. A reason is required. |
| <UiPath path="audience.contacts.delete" /> | Erases the contacts for good (see below). |

</TableScroll>

<Aside type="caution">
  <UiPath path="audience.contacts.addToList" /> subscribes everyone selected, including contacts who left that list in
  the preference center. <UiPath path="audience.contacts.resendOptin" /> emails every selected contact, confirmed or
  not. Filter <UiPath path="audience.contacts.consent" /> by <UiPath path="audience.consentPendingFilter" /> first to
  reach only the contacts who still have to confirm.
</Aside>

If some contacts can't be changed, a **Partly done** panel says how many succeeded and lists the others.

The CSV export has the columns `email`, `first_name`, `last_name`, `company`, `country`, `timezone`, `language`,
`lists`, `tier`, `consent`, `mailbox_provider`, `source`, `joined_at`, `last_open_at`, `last_click_at`, `tags`, then one
column per custom field. Times are in UTC.

## Erase contacts

Erasing removes names, fields, tags, list memberships, consent history and preferences for good. Delivery statistics
stay, without the address, so campaign reports still add up.

<Steps>

1. Tick the contacts and select <UiPath path="audience.contacts.delete" />.

2. Type the number of contacts to confirm, then select **Erase _N_ contacts**.

</Steps>

<Aside type="caution">
  Erasing can't be undone, and it does not add the address to the suppression list. If the person must never be
  emailed again, [suppress](/audience/suppressions/) the address first, then erase the contact.
</Aside>

## Read a contact's profile

Select a contact's name to open the profile.

<Screenshot
  id="contact-profile"
  alt="Sam Rivera's profile: badges Active, Double opt-in, Outlook and Joined via a Brevo import, email stats for 90 days, and a score card at 52, Hot, with a breakdown by rule."
/>

- **Header**: tier, consent, mailbox provider, when and how they joined, and a "Role address · no Broadcasts" badge
  for addresses such as `info@`. The figures cover emails sent in the last 90 days, human opens, clicks and the last
  open.
- **Fields**: built-in and custom fields, tags and the address check result. **Edit** changes them; the audit log
  keeps the old and new values. The email address can't be edited.
- **Consent per list**: each list's status with how and when they subscribed or confirmed, from which IP address, and
  the consent text version. With texting set up, email, SMS and WhatsApp consent show side by side.
- **Activity**: every delivery, open, click and consent change, filterable by **Deliveries**, **Engagement** and
  **Consent**. Each delivery names the [sending provider](/reference/glossary/#sending-provider) that carried it, marks
  failovers and retries, and shows the original SMTP code for bounces.
- Cards for the [score](/audience/scoring/), referrals, paid subscription and purchases appear when those features
  are in use.

The header actions:

- <UiPath path="audience.profile.resendOptin" /> sends a new confirmation email. If no System provider can send it,
  the page gives you the link to share instead.
- <UiPath path="audience.profile.exportData" /> downloads a JSON file with the full profile, consent evidence, up to
  10,000 messages and events, and any suppression. The export is in the audit log.
- <UiPath path="audience.profile.suppress" /> puts the address on the shared suppression list, with a reason.
- **Open preference center as _name_** (under **Consent per list**) opens the contact's preference page in a new tab.
  Opening it is logged.

## Check that it worked

- A saved view appears in the **Saved views** row with its count.
- After a bulk action, a message says how many contacts changed.
- Exports and erasures appear in <UiPath path="nav.settings > settings.audit" />.

## Troubleshooting

- **A button is disabled** → hover it to see the permission it needs, then ask an Owner or Admin.
- **"_email_ is on the suppression list"** when adding a contact → remove the address from the suppression list
  with a reason, but only if they gave you a new opt-in.
- **"No System provider could send the confirmation"** → connect a sending provider to the System stream in
  [routing](/providers/routing/), or share the link from the profile.
- **A saved view has the wrong name** → the app can't rename or delete views yet. The API can delete one with
  [Delete a contact view](/api/operations/delete-contact-view/); a personal view can be deleted only by the person who
  created it.
