L’assistant IA de rédaction d’e-mails de ReputeCast suggère des objets, réécrit des textes, traduit des
[versions linguistiques](/fr/campaigns/languages/), rédige des textes alternatifs et des brouillons de segments avec un
modèle que vous connectez vous-même : Anthropic, OpenAI, Google Gemini, Azure OpenAI ou un serveur compatible OpenAI sur
votre propre réseau. L’assistant est désactivé tant que vous n’avez pas connecté de modèle, le fournisseur facture votre
propre compte, et rien ne change dans un e-mail tant qu’une personne n’a pas accepté la suggestion.

## Avant de commencer

- Connecter, modifier ou déconnecter le modèle exige `integrations:manage`, une
  [autorisation sensible](/fr/reference/glossary/#sensitive-permission) que seules des personnes peuvent détenir (le
  Propriétaire et l’Admin en disposent). Les membres disposant de `integrations:view` peuvent ouvrir la page et consulter
  la consommation et le journal d’activité.
- Demander des suggestions exige `ai:use`. Le Propriétaire, l’Admin et l’Éditeur en disposent ; un Observateur peut lire
  les résumés de rapports conservés, mais ne peut pas demander de suggestions. Les clés API et les
  [agents MCP](/fr/developers/mcp/) ne peuvent pas détenir `ai:use`. Chaque fonctionnalité exige aussi l’autorisation
  correspondant à ce qu’elle modifie, par exemple `campaigns:edit` dans l’éditeur ou `segments:edit` pour les brouillons
  de segments. Lisez [Autorisations et rôles](/fr/reference/permissions/).
- Munissez-vous d’une clé API du fournisseur du modèle, ou de l’adresse de votre propre serveur.
- Un espace de travail a un seul modèle à la fois. Pour changer de fournisseur, déconnectez d’abord le fournisseur
  actuel.

## Connecter un modèle

<Steps>

1. Ouvrez <UiPath path="nav.settings > settings.integrations" /> et trouvez le groupe
   <UiPath path="integrations.groupAi" />, ou ouvrez directement
   <UiPath path="nav.settings > settings.integrations > ai.title" />. Choisissez <UiPath path="ai.connectModel" />.

2. Choisissez le fournisseur et remplissez ses champs :

   - **Anthropic, OpenAI, Google Gemini** : la clé API et le modèle.
   - **Azure OpenAI** : l’endpoint (en HTTPS, par exemple `https://acme.openai.azure.com`), le nom du déploiement, la clé
     API, une version d’API facultative et le modèle qu’exécute le déploiement (utilisé pour les prix). Vos données
     restent dans la région de votre ressource Azure.
   - **Compatible OpenAI** (Ollama, vLLM, LM Studio et autres) : l’adresse du serveur, `/v1` compris, un nom facultatif
     et, si le serveur en exige une, une clé API.

   La liste des modèles vient d’abord de la grille de prix de ReputeCast, puis du fournisseur une fois la clé (ou
   l’adresse du serveur) renseignée. Si votre modèle n’est pas listé, choisissez **Saisir un nom de modèle…**.

   La clé est en écriture seule : elle est stockée chiffrée et n’est plus jamais affichée, pas même à vous. Une clé
   enregistrée ne part qu’à l’adresse pour laquelle elle a été saisie : depuis la version 1.5.0, quand vous changez un
   endpoint Azure OpenAI ou l’adresse d’un serveur compatible OpenAI en laissant la clé vide, la boîte de dialogue vous
   demande de coller de nouveau la clé.

3. Définissez le plafond mensuel. Pour les fournisseurs hébergés, la boîte de dialogue propose au départ 25 $ par mois,
   d’après les prix de ReputeCast par million de tokens (vous pouvez modifier les prix). Un serveur compatible OpenAI
   commence avec un plafond de 20 000 000 de tokens par mois. Après la connexion, vous pouvez passer à un plafond en
   dollars, en tokens ou sans plafond.

4. Choisissez **Connecter**. ReputeCast envoie d’abord un prompt de test fixe, sans aucun contenu de l’espace de travail
   (« Reply with the word Ready. »), et n’enregistre rien si le test échoue.

</Steps>

### Modèles sur votre propre réseau

Un serveur compatible OpenAI sur une adresse privée ou loopback (comme `http://ollama.acme.internal:11434/v1`) est refusé
avec « Connexion impossible à une adresse privée » tant qu’un exploitant n’a pas défini
[`providers.allow_private_networks`](/fr/reference/configuration/) sur `true`
(`REPUTECAST_PROVIDERS__ALLOW_PRIVATE_NETWORKS=true`). Les noms d’hôte se terminant par `.internal` ou `.localhost`
comptent comme privés. Les adresses link-local et les adresses de métadonnées cloud sont toujours refusées. Lisez
[Sécurité et durcissement](/fr/self-hosting/security/).

## Ce que fait l’assistant

Chaque fonctionnalité a son propre interrupteur sous **Fonctionnalités et ce que chacune envoie** ; les sept sont
activées au départ.

| Fonctionnalité | Où la trouver | Ce que vous obtenez |
|---|---|---|
| Idées d’objet | **Idées** à côté de l’objet dans l’éditeur, ou **Assistant** › **Idées d’objet** | Cinq objets, chacun avec les contrôles d’objet ; **Utiliser** en applique un |
| Réécrire, raccourcir et changer le ton | La barre d’outils du texte : **Raccourcir**, **Plus chaleureux**, **Plus formel**, **Plus direct**, **Avec une consigne…** | Le texte réécrit, présenté comme une modification de l’original |
| Traduire une version linguistique | **Traduire en &lt;langue&gt ; avec l’IA** dans le menu des langues de l’éditeur, la boîte de dialogue d’ajout de langue ou la vue de comparaison | Une traduction côte à côte, à accepter bloc par bloc ou en une fois |
| Texte alternatif | **Suggérer un texte alternatif** dans les réglages d’une image et dans le panneau d’accessibilité | Une description avec des contrôles ; « Image décorative » reste votre choix |
| Corrections d’accessibilité | **Suggérer une correction** dans le panneau d’accessibilité | Un texte de lien plus clair |
| Décrire le segment | La carte **Décrire le segment** de l’éditeur de segments, puis **Rédiger** | Des conditions marquées comme ajoutées ou retirées, avec le décompte en direct |
| Résumés de rapports | **Résumer les résultats** sur un rapport de campagne | Un résumé à conserver, modifier ou rejeter |

Sur un téléphone, le menu **Assistant** de l’éditeur est l’étincelle de sa barre du haut, et ses cartes s’affichent sous
l’e-mail. Le texte alternatif et les corrections d’accessibilité y indiquent <UiPath path="ai.suggest.largerScreen" /> :
ils s’ouvrent dans le panneau Propriétés, dont disposent les écrans plus grands.

### Rien ne change sans vous

- Une requête ne part que lorsque quelqu’un clique. La réponse du modèle est une suggestion : **Accepter**, **Modifier**
  (l’ouvre d’abord dans le bloc), **Refuser** ou **Réessayer**. Pour les idées d’objet, vous choisissez **Utiliser** ;
  les résumés de rapports proposent **Conserver** et **Rejeter**.
- Les réécritures et les textes alternatifs acceptés sont enregistrés par l’éditeur comme n’importe quelle modification :
  ils apparaissent donc dans l’[historique des versions](/fr/campaigns/composer/) et peuvent être annulés.
- Les variables de personnalisation et les liens que le modèle a modifiés sont rétablis depuis votre original, et la
  carte indique combien.
- Une suggestion ne peut être tranchée que par la personne qui l’a demandée, dans les 24 heures.
- Une traduction acceptée en entier est marquée « Traduite par l’IA · non relue » jusqu’à ce que quelqu’un la marque
  comme relue ou la modifie.
- Les brouillons qu’un agent IA rédige par le [serveur MCP](/fr/developers/mcp/) sont compilés, contrôlés et versionnés
  comme les enregistrements de l’éditeur, et n’annulent jamais une approbation.

L’assistant ne s’occupe pas de la réputation de l’expéditeur. Les questions sur les listes de blocage, DMARC ou la raison
pour laquelle des e-mails arrivent en spam n’envoient rien au modèle ; ReputeCast vous renvoie plutôt vers la
[délivrabilité](/fr/deliverability/overview/).

## Ce qui quitte votre instance

Seulement ce sur quoi une personne travaille, seulement quand elle le demande, et seulement pour les fonctionnalités
activées :

- **Idées d’objet et traduction** : le texte de l’e-mail (sans les images), l’objet, le texte d’aperçu et la langue.
- **Réécriture** : le paragraphe sélectionné et votre consigne.
- **Texte alternatif** : l’image (redimensionnée à 1 024 px de large), son nom de fichier et le texte qui l’entoure. Le
  modèle doit savoir lire les images ; avec un modèle texte uniquement, le texte alternatif reste désactivé.
- **Corrections d’accessibilité** : le texte du lien, son adresse et la phrase qui l’entoure.
- **Brouillons de segments** : votre description, les noms des champs, des opérateurs et des options de l’éditeur de
  segments (listes, tags, formules) et les conditions actuelles.
- **Résumés de rapports** : les totaux et les taux, les trois liens principaux, les taux par fournisseur de messagerie
  et les motifs de désabonnement.

Jamais envoyés : les contacts, adresses, noms, valeurs de champs, listes de destinataires, clés ou identifiants. Les
variables Liquid partent telles qu’elles sont écrites (un aperçu « en tant que contact » n’est jamais envoyé), et rien
de l’assistant ne va à HostRepute.

## Plafond, consommation et journal d’activité

La consommation correspond au nombre de tokens que signale le fournisseur multiplié par les prix de la page, cumulé à
partir du 1er du mois dans le fuseau horaire de l’espace de travail.

<LimitsTable area="ai" />

- À 80 % du plafond, les membres disposant de `integrations:manage` reçoivent une notification (dans l’application et
  par e-mail). À 100 %, l’assistant se met en pause jusqu’au 1er ; l’édition, les envois et les rapports continuent
  normalement. Relever le plafond le relance.
- Le **Journal d’activité de l’IA** conserve pendant 90 jours qui a demandé, quand, quelle fonctionnalité, sur quoi, le
  modèle, les tokens, le coût et le résultat, sans le texte envoyé ni renvoyé.
- La connexion, les changements de modèle ou de clé, le plafond, les prix et les interrupteurs des fonctionnalités sont
  enregistrés dans le [journal d’audit](/fr/team/audit-log/). Les requêtes IA individuelles ne le sont pas.

## Vérifier le résultat

- La page affiche **Connecté**, le modèle et une heure de **Dernier test**.
- Dans l’éditeur, le menu **Assistant** liste les fonctionnalités que vous avez activées.

## Dépannage

- **« Erreur · clé refusée »** : le fournisseur a refusé la clé. Toutes les fonctionnalités s’arrêtent jusqu’à ce que vous
  choisissiez **Remplacer la clé** ou qu’un **Tester la connexion** réussisse.
- **« Connexion impossible à une adresse privée »** : voir
  [Modèles sur votre propre réseau](#modèles-sur-votre-propre-réseau).
- **« L’adresse a changé : collez à nouveau la clé API »** : ReputeCast n’envoie pas une clé enregistrée à une nouvelle
  adresse. Collez la clé avec le nouvel endpoint ou la nouvelle adresse du serveur.
- **Azure : mauvais déploiement après Changer de modèle** : changer de modèle définit aussi le nom du déploiement sur le
  modèle choisi. Choisissez **Saisir un nom de modèle…** et saisissez le nom du déploiement.
- **Le texte alternatif reste désactivé** : le modèle ne lit pas les images. Choisissez un modèle qui le fait.
- **« Le budget IA de ce mois (…) est épuisé »** : relevez le plafond sous **Plafond mensuel** › **Modifier**, ou
  attendez le 1er.
- **La limite de débit du fournisseur** : la carte affiche un compte à rebours (« Réessayer dans N s ») ; rien ne change
  dans l’e-mail.
