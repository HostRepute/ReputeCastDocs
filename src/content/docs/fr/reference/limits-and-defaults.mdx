Cette page liste les limites ReputeCast et les valeurs par défaut auxquelles renvoient les guides, avec un tableau par domaine. **Comment le modifier** nomme le paramètre, la clé de configuration ou le champ d’API qui modifie une valeur, avec sa plage autorisée ; _Non modifiable_ signifie que la valeur est définie dans le code.

Les paramètres de l’application s’appliquent à un espace de travail, sauf ceux de <UiPath path="shell.userMenuInstanceAdmin" />, qui s’appliquent à toute l’instance comme les clés de configuration (voir la [référence de la configuration](/fr/reference/configuration/)). Les valeurs qui protègent un envoi en cours sont expliquées dans [suivre un envoi et la pause automatique](/fr/campaigns/live-monitor/), et les limites de débit de l’API dans [limites de débit](/fr/developers/api-rate-limits/).
