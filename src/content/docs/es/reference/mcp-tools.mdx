Esta página es la lista de herramientas MCP del servidor [MCP](/es/reference/glossary/#mcp) de ReputeCast, con sus recursos y sus prompts.

El servidor escucha en `<public URL>/mcp` (Streamable HTTP). Un [agente MCP](/es/reference/glossary/#mcp-agent) se autentica con `Authorization: Bearer rc_agent_…`; crea los agentes en <UiPath path="nav.settings > settings.keys" />. [Conectar agentes de IA con MCP](/es/developers/mcp/) muestra cómo configurar el cliente.

- **Permiso**: lo que necesita el agente para llamar a la herramienta. Sin él, la llamada se deniega y ReputeCast registra una propuesta para un miembro que tenga el permiso. Un agente nunca hace más de lo que puede hacer el miembro que lo creó.
- **Efecto**: _Lee datos_ no cambia nada. _Cambia datos_ actúa de inmediato. _Propone; una persona lo aprueba_ crea una solicitud que un miembro confirma en ReputeCast; hasta entonces no ocurre nada.
- Cada llamada a una herramienta, permitida, denegada o fallida, se anota en el [registro de auditoría](/es/team/audit-log/) con el nombre del agente.
- **Informes**: `get_campaign_report` devuelve el mismo informe que muestra la aplicación, con las aperturas humanas, las protegidas por privacidad y las de escáneres por separado, y las quejas solo donde se notifican; `share_campaign_report` crea un enlace de solo lectura que siempre caduca. Consulta [leer los informes de campaña](/es/campaigns/reports/).
