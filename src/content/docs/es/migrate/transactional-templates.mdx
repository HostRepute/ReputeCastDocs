Para migrar plantillas de Postmark, o las plantillas que tienes en SendGrid, Mailgun o Notifuse, conectas ReputeCast a la cuenta una vez, eliges las plantillas y lees un informe de conversión antes de que se cree nada. Cada plantilla se reescribe en [Liquid](/es/campaigns/personalization/) de ReputeCast, sus variables se declaran a partir de lo que usa y llega como borrador: no se publica nada, y tu aplicación sigue enviando las versiones publicadas hasta que alguien publique un borrador.

## Antes de empezar

- Necesitas el permiso `transactional:edit` (lo tienen Propietario, Administrador y Editor). Solo las personas pueden ejecutar una importación, no las claves de API.
- Consigue la credencial de tu origen. La clave se guarda cifrada solo para esta importación y se descarta cuando termina.

  | Origen                    | Qué pegar                                                                                                                                                                                                                                                                                       |
  | ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
  | Postmark                  | Un server API token, de la pestaña **API Tokens** del servidor. Fuente: [Postmark, What are the Account and Server API Tokens](https://postmarkapp.com/support/article/1008-what-are-the-account-and-server-api-tokens)                                                                      |
  | SendGrid                  | Una clave de API con Custom Access que incluya acceso de lectura a Template Engine, de **Settings** › **API Keys**. Fuente: [SendGrid, API Keys](https://www.twilio.com/docs/sendgrid/ui/account-and-settings/api-keys)                                                                     |
  | Mailgun                   | Una clave de API de la cuenta, del menú del perfil › **API Security**, más la región de tu cuenta (US o EU). Fuente: [Mailgun, Where can I find my API keys](https://help.mailgun.com/hc/en-us/articles/203380100-Where-can-I-find-my-API-keys-and-SMTP-credentials)                        |
  | Notifuse                  | La dirección de tu instancia y una clave de API del espacio de trabajo con Templates read. Fuente: [Notifuse, Admins & API Keys](https://docs.notifuse.com/features/admins-api-keys)                                                                                                        |
  | Archivos MJML o HTML      | Hasta 50 archivos `.mjml`, `.html` o `.htm` de hasta 2 MB cada uno, en UTF-8                                                                                                                                                                                                                    |

  Fuentes comprobadas en octubre de 2026.

## Importar las plantillas

<Steps>

1. Abre <UiPath path="nav.transactional > transactional.common.importTemplates" /> y elige dónde están ahora las plantillas.

   <Screenshot
     id="transactional"
     alt="La página de plantillas transaccionales, con el botón Importar plantillas junto a Nueva plantilla arriba a la derecha y 16 plantillas en la lista de abajo."
   />

2. Conecta el origen. Para Postmark, pega el token en <UiPath path="transactional.import.postmarkKey" />; para SendGrid, pega la clave de API. Para Mailgun, pega la clave en <UiPath path="transactional.import.mailgunKey" /> y elige la <UiPath path="transactional.import.mailgunRegion" />; rellena <UiPath path="transactional.import.mailgunDomain" /> para leer las plantillas de un dominio, o déjalo vacío para leer todos los dominios que no estén desactivados. Para Notifuse, introduce la <UiPath path="transactional.import.notifuseAddress" />, como `https://notifuse.example.com`, y la clave de API. Para <UiPath path="transactional.import.files" />, suelta o elige los archivos: se convierten al instante, y el siguiente paso es el informe.

3. Elige las plantillas. ReputeCast preselecciona las plantillas activas de Postmark, todas las plantillas de SendGrid y Mailgun, y las plantillas transaccionales de Notifuse; marca cualquier otra que quieras.

4. Conviértelas y lee el informe. Cada plantilla recibe uno de los resultados de la tabla de abajo, con la línea y la construcción que hay detrás de cada nota.

5. Impórtalas como borradores. El informe muestra el ID de ReputeCast que recibe cada borrador; abre cada uno, corrige lo que pide el informe y publícalo desde el editor de plantillas.

</Steps>

| Resultado                                                 | Significado                                                                                                     |
| --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| <UiPath path="transactional.import.resultConverted" />  | No hay nada que requiera tu atención.                                                                           |
| <UiPath path="transactional.import.resultNotes" />      | Una construcción se reescribió con un cambio visible, como `{{#each items}}`, que pasa a ser `{% for item in items %}`. |
| <UiPath path="transactional.import.resultManual" />     | Una construcción se dejó tal cual, y el borrador muestra un error de Liquid hasta que la sustituyas.            |
| <UiPath path="transactional.import.resultFailed" />     | El origen no devolvió la plantilla; el informe explica por qué.                                                |

## Cómo se convierten las plantillas

- **Los ID** salen del alias o del nombre en el origen: letras minúsculas, dígitos y guiones, hasta 64 caracteres. Cuando un ID ya está en uso, el borrador recibe `-2`, `-3`, etc., y el informe lo indica.
- **Asuntos:** las plantillas de Postmark, SendGrid y Notifuse conservan su asunto. Mailgun solo conserva el asunto cuando la versión de la plantilla tiene una cabecera `Subject`; un archivo lo toma de `<mj-title>` en MJML o de `<title>` en HTML, y `<mj-preview>` de MJML pasa a ser el preencabezado. Si no hay ninguno, el asunto queda vacío y el informe te pide que lo escribas.
- **Diseños:** una plantilla de Postmark que usa un layout recibe el layout fusionado en `{{{ @content }}}`.
- **Versiones:** SendGrid y Mailgun dan la versión activa. Una plantilla de SendGrid sin versión activa trae su primera versión, con una nota.
- **Las variables** se declaran a partir de lo que usa cada plantilla, con un tipo. Los datos de prueba de SendGrid y de Notifuse se convierten en valores de ejemplo y en el primer conjunto de datos de prueba. Un nombre de variable que la API no admite, como `first-name`, se cambia (`first_name`) en toda la plantilla, y el informe te dice qué debe enviar tu aplicación en su lugar.
- **Las plantillas de Notifuse** ya están en Liquid. Los campos de contacto se convierten en variables simples (`contact.first_name` pasa a ser `first_name`, `contact.email` pasa a ser `to.email`), y `notification_center_url` pasa a ser `preferences_url`. Las plantillas del editor visual llegan como MJML.

Reescrituras y correcciones manuales habituales:

<TableScroll label="Cómo se convierten las plantillas" wrap>

| En el origen                                                   | En ReputeCast                                                                   |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `{{#each items}}` (Handlebars, Mustachio)                     | `{% for item in items %}`                                                       |
| Una sección como `{{#person}}` o `{{#with author}}`           | `{% if person %}`; los nombres dentro de ella empiezan ahora por `person.`      |
| `{{{ pm:unsubscribe }}}` de Postmark, `{{{unsubscribe}}}` de SendGrid | `{{ unsubscribe_url }}`                                                  |
| `<%asm_preferences_raw_url%>` de SendGrid                      | `{{ preferences_url }}`                                                         |
| `{{insert name "default=Customer"}}` de SendGrid               | `{{ name \| default: "Customer" }}`                                             |
| `%recipient.first_name%`, `%recipient_email%` de Mailgun       | `{{ first_name }}`, `{{ to.email }}`                                            |
| Un parcial como `{{> footer}}`, o `{% include %}` de Liquid     | Corrección manual: las plantillas no pueden incluir otros archivos. Usa una sección guardada. |
| Un helper o un filtro que ReputeCast no tiene, como `formatCurrency` o `money` | Corrección manual: sustitúyelo, por ejemplo enviando el valor ya formateado en los datos de la llamada. |
| `view_in_browser_url`                                          | Corrección manual: el correo transaccional no tiene versión web. Quita el enlace. |
| MJML que no compila, un bloque que nunca se cierra            | Corrección manual, con el número de línea                                       |

</TableScroll>

<Aside type="note">
Los borradores importados nunca llegan a nadie por sí solos. Hasta que se publica un borrador, la API de envío sigue usando la versión publicada de la plantilla, y una plantilla que nunca se ha publicado no se puede enviar.
</Aside>

## Comprobar que funciona

El último paso enumera todos los borradores con su ID de ReputeCast y cuántos requieren una corrección manual. Los borradores están en <UiPath path="nav.transactional > transactional.common.tabTemplates" />; abre uno para ver sus variables, sus datos de prueba y cualquier error de Liquid que mencionara el informe. Envíate una prueba desde el editor antes de publicarlo.

## Solución de problemas

- **"Postmark respondió 401: este token es de otro servidor o se revocó."** (o 403): copia el token del servidor cuyas plantillas quieres.
- **"SendGrid respondió 403: esta clave no puede leer plantillas."**: edita la clave en SendGrid y dale acceso de lectura a Template Engine.
- **"Mailgun respondió 401: la clave de API no es correcta o la cuenta está en la otra región."** (o 403): cambia la región o crea una clave de API de cuenta nueva.
- **"Esta cuenta de Mailgun no tiene dominios, así que no tiene plantillas que importar."**: en Mailgun, las plantillas pertenecen a los dominios; añade primero el dominio allí, o introduce el dominio de envío correcto.
- **"… ocupa más de 2 MB."** o **"Hasta 50 archivos a la vez"**: divide la subida; cada subida es una importación.
- **"… está limitando la velocidad de las solicitudes (429). Vuelve a intentarlo en un minuto."**: ReputeCast lo reintentó tres veces, respetando el `Retry-After` del proveedor. Espera un minuto y vuelve a convertir.
- **"Esta importación ya no tiene clave de API. Vuelve a empezar y pega la clave."**: la importación terminó o se canceló, lo que descarta la clave. Inicia una importación nueva.
