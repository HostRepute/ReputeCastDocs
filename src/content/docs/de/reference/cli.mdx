Diese Seite listet jeden Befehl der reputecast-CLI auf, also der einzelnen Binärdatei `reputecast`, die den Server, die Worker und die Wartungsaufgaben ausführt.

Im Docker-Image führen Sie einen Befehl im App-Container aus: `docker compose exec app /usr/local/bin/reputecast <command>`. Die Konfiguration stammt aus denselben Quellen wie bei `reputecast serve` (siehe [ReputeCast konfigurieren](/de/self-hosting/configuration/)); übergeben Sie also `--config` oder die `REPUTECAST_*`-Variablen, die der Server nutzt.

## Exit-Codes

<TableScroll label="Exit-Codes der CLI" wrap>

| Code | Bedeutung                                                                                                                                                                                                                                                                                                  |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `0`  | Der Befehl war erfolgreich.                                                                                                                                                                                                                                                                                |
| `1`  | Der Befehl ist fehlgeschlagen: ein Datenbank-, Netzwerk- oder Konfigurationsfehler, ein unbekanntes Flag oder eine falsche Anzahl von Argumenten. Außerdem `healthcheck`, wenn der Prozess nicht bereit ist, `doctor`, wenn eine Prüfung fehlschlägt, und `secrets reseal`, wenn sich Werte ohne konfigurierten Schlüssel öffnen lassen. |
| `2`  | ReputeCast hat die Anfrage abgelehnt, bevor es etwas getan hat: `user reset-2fa` ohne `--reason`, ein `--password`, das gegen die Passwortrichtlinie verstößt, ein unbekanntes `seed --sample` oder `seed` (ohne `--force`) bzw. `demo send` außerhalb von `REPUTECAST_ENV=development`.                    |

</TableScroll>

Jeder Fehler wird als `Error: <message>` auf die Standardfehlerausgabe geschrieben.
