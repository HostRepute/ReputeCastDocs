Diese Seite ist die Liste der MCP-Tools des [MCP](/de/reference/glossary/#mcp)-Servers von ReputeCast, mit seinen Ressourcen und Prompts.

Der Server lauscht unter `<public URL>/mcp` (Streamable HTTP). Ein [MCP-Agent](/de/reference/glossary/#mcp-agent) authentifiziert sich mit `Authorization: Bearer rc_agent_…`; Agenten legen Sie unter <UiPath path="nav.settings > settings.keys" /> an. [KI-Agenten über MCP verbinden](/de/developers/mcp/) zeigt die Einrichtung der Clients.

- **Berechtigung**: was der Agent braucht, um das Tool aufzurufen. Ohne sie wird der Aufruf verweigert, und ReputeCast erfasst einen Vorschlag für ein Mitglied, das die Berechtigung hat. Ein Agent tut nie mehr, als das Mitglied tun kann, das ihn angelegt hat.
- **Wirkung**: _Liest Daten_ ändert nichts. _Ändert Daten_ wirkt sofort. _Schlägt vor; eine Person gibt frei_ erstellt eine Anfrage, die ein Mitglied in ReputeCast bestätigt; bis dahin geschieht nichts.
- Jeder Tool-Aufruf, ob erlaubt, verweigert oder fehlgeschlagen, wird mit dem Namen des Agenten in das [Audit-Protokoll](/de/team/audit-log/) geschrieben.
- **Berichte**: `get_campaign_report` liefert denselben Bericht, den die App zeigt, mit menschlichen, durch Datenschutzfunktionen geschützten und von Scannern ausgelösten Öffnungen getrennt und Beschwerden nur dort, wo sie gemeldet werden; `share_campaign_report` erstellt einen Ansichtslink, der immer abläuft. Siehe [Kampagnenberichte lesen](/de/campaigns/reports/).
