Diese Seite listet die Limits von ReputeCast und die Standardwerte, auf die sich die Anleitungen beziehen, mit einer Tabelle je Bereich. **Ändern über** nennt die Einstellung, den Konfigurationsschlüssel oder das API-Feld, das einen Wert ändert, mit dem erlaubten Bereich; _Fest vorgegeben_ bedeutet, dass der Wert im Code festgelegt ist.

App-Einstellungen gelten für einen Arbeitsbereich, außer denen unter <UiPath path="shell.userMenuInstanceAdmin" />, die wie Konfigurationsschlüssel für die ganze Instanz gelten (siehe die [Konfigurationsreferenz](/de/reference/configuration/)). Die Werte, die einen laufenden Versand schützen, erklärt [Versand überwachen und automatisch pausieren](/de/campaigns/live-monitor/), die Rate-Limits der API erklärt [Rate-Limits](/de/developers/api-rate-limits/).

- [ReputeCast konfigurieren](/de/self-hosting/configuration/) erklärt die Ebenen der Konfiguration.
