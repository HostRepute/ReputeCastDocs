Der KI-Assistent für E-Mails von ReputeCast schlägt Betreffzeilen vor, schreibt Texte um, übersetzt
[Sprachversionen](/de/campaigns/languages/), schreibt Alternativtexte und entwirft Segmente, und zwar mit einem Modell,
das Sie selbst verbinden: Anthropic, OpenAI, Google Gemini, Azure OpenAI oder ein OpenAI-kompatibler Server in Ihrem
eigenen Netzwerk. Der Assistent ist aus, bis Sie ein Modell verbinden, der Anbieter rechnet über Ihr eigenes Konto ab,
und in einer E-Mail ändert sich nichts, bis eine Person den Vorschlag übernimmt.

## Bevor Sie beginnen

- Zum Verbinden, Ändern oder Trennen des Modells brauchen Sie `integrations:manage`, eine
  [sensible Berechtigung](/de/reference/glossary/#sensitive-permission), die nur Menschen haben können (Inhaber und
  Admin haben sie). Mitglieder mit `integrations:view` können die Seite öffnen und Nutzung und Aktivitätsprotokoll
  lesen.
- Zum Anfordern von Vorschlägen brauchen Sie `ai:use`. Inhaber, Admin und Bearbeiter haben diese Berechtigung; ein
  Betrachter kann behaltene Berichtszusammenfassungen lesen, aber keine Vorschläge anfordern. API-Schlüssel und
  [MCP-Agenten](/de/developers/mcp/) können `ai:use` nicht haben. Jede Funktion braucht außerdem die Berechtigung für
  das, was sie ändert, zum Beispiel `campaigns:edit` im Editor oder `segments:edit` für Segmententwürfe. Lesen Sie
  [Berechtigungen und Rollen](/de/reference/permissions/).
- Sie brauchen einen API-Schlüssel des Modellanbieters oder die Adresse Ihres eigenen Servers.
- Ein Arbeitsbereich hat jeweils ein Modell. Um den Anbieter zu wechseln, trennen Sie zuerst den aktuellen.

## Modell verbinden

<Steps>

1. Öffnen Sie <UiPath path="nav.settings > settings.integrations" /> und suchen Sie die Gruppe
   <UiPath path="integrations.groupAi" />, oder öffnen Sie direkt
   <UiPath path="nav.settings > settings.integrations > ai.title" />. Wählen Sie
   <UiPath path="ai.connectModel" />.

2. Wählen Sie den Anbieter und füllen Sie seine Felder aus:

   - **Anthropic, OpenAI, Google Gemini**: der API-Schlüssel und das Modell.
   - **Azure OpenAI**: der Endpunkt (HTTPS, zum Beispiel `https://acme.openai.azure.com`), der Name der
     Bereitstellung, der API-Schlüssel, optional eine API-Version und das Modell, das die Bereitstellung ausführt (für
     die Preise). Ihre Daten bleiben in der Region Ihrer Azure-Ressource.
   - **OpenAI-kompatibel** (Ollama, vLLM, LM Studio und andere): die Serveradresse einschließlich `/v1`, optional ein
     Name und, falls der Server einen braucht, ein API-Schlüssel.

   Die Liste der Modelle kommt zuerst aus der Preisliste von ReputeCast und dann vom Anbieter, sobald der Schlüssel
   (oder die Serveradresse) eingetragen ist. Steht Ihr Modell nicht in der Liste, wählen Sie **Modellnamen eingeben…**.

   Der Schlüssel ist nicht auslesbar: Er wird verschlüsselt gespeichert und nie wieder angezeigt, auch Ihnen nicht. Ein
   gespeicherter Schlüssel geht nur an die Adresse, für die er eingegeben wurde: Wenn Sie seit Version 1.5.0 einen
   Endpunkt von Azure OpenAI oder die Adresse eines OpenAI-kompatiblen Servers ändern und den Schlüssel leer lassen,
   bittet der Dialog Sie, den Schlüssel erneut einzufügen.

3. Legen Sie das Monatslimit fest. Bei gehosteten Anbietern beginnt der Dialog mit 25 $ im Monat und rechnet mit den
   Preisen von ReputeCast pro Million Token (Sie können die Preise bearbeiten). Ein OpenAI-kompatibler Server beginnt
   mit einem Token-Limit von 20.000.000 Token im Monat. Nach dem Verbinden können Sie zu Dollar, Token oder „Kein Limit“
   wechseln.

4. Wählen Sie **Verbinden**. ReputeCast sendet zuerst einen festen Test-Prompt ohne Inhalte aus dem Arbeitsbereich
   („Antworten Sie mit dem Wort Ready.“) und speichert nichts, wenn der Test fehlschlägt.

</Steps>

### Modelle im eigenen Netzwerk

Ein OpenAI-kompatibler Server unter einer privaten oder Loopback-Adresse (etwa `http://ollama.acme.internal:11434/v1`)
wird mit „Keine Verbindung zu einer privaten Adresse möglich“ abgelehnt, bis ein Serverbetreiber
[`providers.allow_private_networks`](/de/reference/configuration/) auf `true` setzt
(`REPUTECAST_PROVIDERS__ALLOW_PRIVATE_NETWORKS=true`). Hostnamen, die auf `.internal` oder `.localhost` enden, gelten
als privat. Link-Local-Adressen und Metadatenadressen von Cloud-Anbietern werden immer abgelehnt. Lesen Sie
[Sicherheit und Härtung](/de/self-hosting/security/).

## Was der Assistent kann

Jede Funktion hat unter **Funktionen und was jede sendet** einen eigenen Schalter; alle sieben sind anfangs aktiv.

| Funktion | Wo Sie sie finden | Was Sie erhalten |
|---|---|---|
| Betreffideen | **Ideen** neben dem Betreff im Editor oder **Assistent** › **Betreffideen** | Fünf Betreffzeilen, jede mit den Betreffprüfungen; **Verwenden** übernimmt eine davon |
| Umschreiben, kürzen, Tonfall ändern | Die Textwerkzeugleiste: **Kürzen**, **Freundlicher**, **Förmlicher**, **Direkter**, **Mit Anweisung…** | Den umgeschriebenen Text als Änderung gegenüber dem Original |
| Sprachversion übersetzen | **Version auf &lt;Sprache&gt; mit KI übersetzen** im Sprachmenü des Editors, im Dialog „Sprache hinzufügen“ oder in der Vergleichsansicht | Eine Übersetzung nebeneinander, die Sie Block für Block oder komplett übernehmen |
| Alternativtext | **Alternativtext vorschlagen** in den Einstellungen eines Bilds und im Bereich Barrierefreiheit | Eine Beschreibung mit Prüfungen; „Dekoratives Bild“ bleibt Ihre Entscheidung |
| Korrekturen für Barrierefreiheit | **Korrektur vorschlagen** im Bereich Barrierefreiheit | Klareren Linktext |
| Segment beschreiben | Die Karte **Segment beschreiben** im Segment-Editor, dann **Entwerfen** | Bedingungen, markiert als Hinzugefügt und Entfernt, mit der Live-Zählung |
| Berichtszusammenfassungen | **Ergebnisse zusammenfassen** in einem Kampagnenbericht | Eine Zusammenfassung zum Behalten, Bearbeiten oder Verwerfen |

Auf dem Smartphone ist das Menü **Assistent** des Editors das Funkeln-Symbol in seiner oberen Leiste, und seine Karten
erscheinen unter der E-Mail. Alternativtext und Korrekturen für Barrierefreiheit zeigen dort
<UiPath path="ai.suggest.largerScreen" />: Sie öffnen sich im Eigenschaftenbereich, den es auf größeren Bildschirmen
gibt.

### Ohne Sie ändert sich nichts

- Eine Anfrage startet erst, wenn jemand klickt. Die Antwort des Modells ist ein Vorschlag: **Übernehmen**,
  **Bearbeiten** (öffnet ihn zuerst im Block), **Verwerfen** oder **Erneut versuchen**. Bei Betreffideen wählen Sie
  **Verwenden**; Berichtszusammenfassungen bieten **Behalten** und **Verwerfen**.
- Übernommene Umformulierungen und Alternativtexte werden wie jede Bearbeitung über den Editor gespeichert, sodass sie
  im [Versionsverlauf](/de/campaigns/composer/) erscheinen und sich rückgängig machen lassen.
- Platzhalter und Links, die das Modell geändert hat, werden aus Ihrem Original wiederhergestellt, und die Karte nennt,
  wie viele.
- Über einen Vorschlag entscheiden kann nur die Person, die ihn angefordert hat, und nur innerhalb von 24 Stunden.
- Eine vollständig übernommene Übersetzung ist als „KI · nicht geprüft“ markiert, bis jemand sie als geprüft markiert
  oder bearbeitet.
- Entwürfe, die ein KI-Agent über den [MCP-Server](/de/developers/mcp/) schreibt, werden wie Speichervorgänge im Editor
  kompiliert, geprüft und versioniert und machen nie eine Freigabe ungültig.

Der Assistent befasst sich nicht mit der Absenderreputation. Fragen zu Blocklisten, DMARC oder dazu, warum E-Mails im
Spam landen, senden nichts an das Modell; ReputeCast verweist Sie stattdessen auf die
[Zustellbarkeit](/de/deliverability/overview/).

## Was Ihre Instanz verlässt

Nur das, woran eine Person gerade arbeitet, nur wenn sie darum bittet, und nur für die Funktionen, die aktiv sind:

- **Betreffideen und Übersetzung**: der Text der E-Mail (ohne Bilder), Betreff, Vorschautext und Sprache.
- **Umschreiben**: der markierte Absatz und Ihre Anweisung.
- **Alternativtext**: das Bild (verkleinert auf 1.024 px Breite), sein Dateiname und der umgebende Text. Das Modell muss
  Bilder lesen können; mit einem reinen Textmodell bleibt der Alternativtext aus.
- **Korrekturen für Barrierefreiheit**: der Linktext, seine Adresse und der umgebende Satz.
- **Segmententwürfe**: Ihre Beschreibung, die Feldnamen, Operatoren und Optionsnamen des Segment-Editors (Listen, Tags,
  Tarife) und die aktuellen Bedingungen.
- **Berichtszusammenfassungen**: Summen und Raten, die drei häufigsten Links, die Raten je Postfachanbieter und die
  Abmeldegründe.

Nie gesendet werden: Kontakte, Adressen, Namen, Feldwerte, Empfängerlisten, Schlüssel oder Zugangsdaten.
Liquid-Platzhalter werden so gesendet, wie sie geschrieben sind (eine Vorschau „als Kontakt“ wird nie gesendet), und
nichts aus dem Assistenten geht an HostRepute.

## Limit, Nutzung und Aktivitätsprotokoll

Die Nutzung ist die vom Anbieter gemeldete Tokenzahl mal den Preisen auf der Seite, summiert ab dem 1. des Monats in
der Zeitzone des Arbeitsbereichs.

<LimitsTable area="ai" />

- Bei 80 % des Limits erhalten Mitglieder mit `integrations:manage` eine Benachrichtigung (in der App und per E-Mail).
  Bei 100 % pausiert der Assistent bis zum 1. des Monats; Bearbeiten, Senden und Berichte laufen wie gewohnt weiter.
  Wird das Limit erhöht, arbeitet der Assistent wieder.
- Das **KI-Aktivitätsprotokoll** bewahrt 90 Tage lang auf, wer wann welche Funktion wofür angefordert hat, mit Modell,
  Token, Kosten und Ergebnis, aber ohne den gesendeten oder zurückgegebenen Text.
- Das Verbinden, Änderungen an Modell oder Schlüssel, am Limit, an den Preisen und an den Schaltern der Funktionen werden
  im [Audit-Protokoll](/de/team/audit-log/) erfasst. Einzelne KI-Anfragen nicht.

## Prüfen, ob es funktioniert hat

- Die Seite zeigt **Verbunden**, das Modell und eine Zeit unter **Letzter Test**.
- Im Editor listet das Menü **Assistent** die Funktionen auf, die Sie eingeschaltet haben.

## Fehlerbehebung

- **„Fehler · Schlüssel abgelehnt“**: Der Anbieter hat den Schlüssel abgelehnt. Alle Funktionen stoppen, bis Sie
  **Schlüssel ersetzen** wählen oder **Verbindung testen** erfolgreich ist.
- **„Keine Verbindung zu einer privaten Adresse möglich“**: siehe
  [Modelle im eigenen Netzwerk](#modelle-im-eigenen-netzwerk).
- **„Die Adresse hat sich geändert: Fügen Sie den API-Schlüssel erneut ein.“**: ReputeCast sendet einen gespeicherten
  Schlüssel nicht an eine neue Adresse. Fügen Sie den Schlüssel zusammen mit dem neuen Endpunkt oder der neuen
  Serveradresse ein.
- **Azure: falsche Bereitstellung nach „Modell ändern“**: Beim Ändern des Modells wird auch der Name der Bereitstellung
  auf das gewählte Modell gesetzt. Wählen Sie **Modellnamen eingeben…** und geben Sie den Namen der Bereitstellung ein.
- **Der Alternativtext bleibt aus**: Das Modell kann keine Bilder lesen. Wählen Sie ein Modell, das es kann.
- **„Monatslimit erreicht“**: Erhöhen Sie das Limit unter **Monatslimit** › **Bearbeiten** oder warten Sie bis zum 1.
  des Monats.
- **Das Rate-Limit des Anbieters**: Die Karte zählt herunter („Erneut versuchen in N s“); in der E-Mail ändert sich
  nichts.
