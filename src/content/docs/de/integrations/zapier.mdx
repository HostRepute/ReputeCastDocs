Mit der ReputeCast-App für Zapier können Sie Ihren Newsletter mit Zapier automatisieren: Ereignisse in ReputeCast
starten Zaps, und aus Ihren anderen Apps fügen Sie Kontakte hinzu, vergeben Tags, erfassen Ereignisse und senden
Transaktions-E-Mails. Die App ist kostenlos und nutzt nur die öffentliche API von ReputeCast, mit einem Schlüssel, der
nur darf, was Sie erlauben.

## Bevor Sie beginnen

- Sie brauchen `integrations:manage` (Inhaber oder Admin). Wie Schlüssel, Status und das Aufrufprotokoll funktionieren,
  lesen Sie unter [Andere Tools verbinden](/de/integrations/overview/).
- Die Server von Zapier rufen Ihre Instanz auf, daher muss ReputeCast aus dem Internet über HTTPS erreichbar sein. Eine
  Instanz in einem privaten Netzwerk kann Zapier nicht nutzen; verwenden Sie stattdessen [n8n](/de/integrations/n8n/)
  im selben Netzwerk.

## Was die App kann

<TableScroll label="Zapier-Trigger" wrap>

| Trigger | ReputeCast-Ereignis | Benötigt |
|---|---|---|
| Contact Subscribed | `contact.subscribed` | `subscribers:view` |
| Contact Unsubscribed | `contact.unsubscribed` | `subscribers:view` |
| Contact Updated | `contact.updated` | `subscribers:view` |
| Form Submitted (optional ein bestimmtes Formular) | `form.submitted` | `subscribers:view` |
| Campaign Sent | `campaign.completed` | `campaigns:view` |
| Transactional Message Bounced | `message.bounced` | `transactional:view` |

</TableScroll>

<TableScroll label="Zapier-Aktionen" wrap>

| Aktion | Was sie tut | Benötigt |
|---|---|---|
| Create or Update Contact | Abgleich über die E-Mail-Adresse; setzt Namen, eigene Felder, Sprache und Tags; fügt mit Single- oder Double-Opt-in zu Listen hinzu | `subscribers:create`, `subscribers:edit` |
| Add Contact to List | Single- oder Double-Opt-in | `subscribers:edit` |
| Add Tag to Contact | Ein oder mehrere Tags | `subscribers:edit` |
| Record Event | Ein API-Ereignis mit Eigenschaften; startet die Automationen, die darauf warten | `subscribers:edit` |
| Send Transactional Email | Eine veröffentlichte Vorlage, ein Empfänger, die zugehörigen Daten und optional eine Sprache | `transactional:send` (sensibel) |

</TableScroll>

Trigger lösen sofort aus. Wenn Sie einen Zap einschalten, entsteht in ReputeCast ein Webhook, der schreibgeschützt als
„Verwaltet von Zapier“ unter <UiPath path="nav.settings > settings.webhooks" /> steht; wenn Sie ihn ausschalten, wird
der Webhook entfernt. Jede Zustellung ist signiert, und die App verwirft eine Zustellung, deren Signatur nicht zum
Signaturschlüssel des Webhooks im Zap passt oder die älter als 5 Minuten ist. Die Payloads der Ereignisse stehen unter
[Webhook-Ereignisse](/de/reference/webhook-events/).

## Zapier verbinden

<Steps>

1. Öffnen Sie in ReputeCast <UiPath path="nav.settings > settings.integrations" />, suchen Sie Zapier unter
   <UiPath path="integrations.groupAutomation" /> und wählen Sie <UiPath path="integrations.connect" />.

2. Legen Sie fest, was Zapier darf. „Transaktions-E-Mail senden“ ist anfangs aus, weil es die sensible Berechtigung
   `transactional:send` braucht; schalten Sie es nur ein, wenn Ihre Zaps Transaktions-E-Mails senden. Wählen Sie
   <UiPath path="integrations.createKey" /> und kopieren Sie den Schlüssel (`rc_live_…`). Er wird einmalig angezeigt.

3. Fügen Sie in Zapier einen ReputeCast-Schritt hinzu und erstellen Sie eine Verbindung mit:

   - **Instance URL**: Ihre ReputeCast-Adresse, zum Beispiel `https://reputecast.acme.io`.
   - **Key**: der Schlüssel aus Schritt 2.

   Die Verbindung fragt ReputeCast, zu welchem Arbeitsbereich der Schlüssel gehört, daher ist sonst nichts nötig.

4. Zurück in ReputeCast zeigt der Dialog zum Verbinden, wie der Aufruf eintrifft („Zapier hat um 14:31 aufgerufen ·
   Verbindung testen · 200“). Wählen Sie **Fertig**.

</Steps>

## Gut zu wissen

- **Benennen Sie Ihre Zaps.** Zapier übergibt Apps die ID eines Zaps, aber nicht seinen Namen. Deshalb hat jeder
  ReputeCast-Schritt ein optionales Feld **Zap Name**. Tragen Sie dort den Namen des Zaps ein, um Ihre Zaps auf der
  Zapier-Seite von ReputeCast auseinanderzuhalten; ohne Namen steht der Zap dort als „Unbenannter Zap“. Die App sendet
  beides im Header `X-ReputeCast-Workflow`.
- **Die Einwilligung bleibt gewahrt.** ReputeCast fügt niemanden einer Liste wieder hinzu, die die Person verlassen hat,
  fügt keine gesperrte Adresse hinzu und sendet keine Transaktions-E-Mail an eine gesperrte Adresse. Solche Ausführungen
  enden als **Halted** mit dem Grund von ReputeCast („rob@example.net hat Beta Program am 2. Okt. … verlassen“). Sie
  zählen nicht als Fehler, daher läuft der Zap für alle anderen weiter.
- **Fehler in den Worten von ReputeCast.** Andere Ablehnungen zeigen den Satz von ReputeCast, zum Beispiel bei einer
  fehlenden Vorlagenvariable („payment-failed v1 needs amount_due.“) oder einer ausgeschalteten Aktion („Ändern Sie die
  Rechte von Zapier unter Einstellungen › Integrationen“).
- **Idempotenz.** Send Transactional Email nimmt einen optionalen **Idempotency Key** an, etwa die ID des auslösenden
  Ereignisses. Läuft derselbe Zap innerhalb von 24 Stunden mit demselben Wert erneut, sendet ReputeCast nichts Neues.
  Lesen Sie [Transaktions-E-Mails über die API senden](/de/developers/transactional-api/).
- **Sprache.** Das Feld **Language** von Send Transactional Email wählt eine Sprachversion der Vorlage (`es`, `de`…).
  Ohne Angabe wird die Sprache des Kontakts verwendet, danach die Ersatzsprache des Arbeitsbereichs.
- **Wenn Sie den Schlüssel** in ReputeCast **rotieren**, funktioniert der alte noch 24 Stunden, damit Sie den neuen
  Schlüssel ohne fehlgeschlagene Ausführungen einfügen können.

## Fehlerbehebung

- **Zapier fordert Sie auf, die Verbindung zu erneuern**: Der Schlüssel wurde widerrufen oder ist abgelaufen. Wählen Sie
  in ReputeCast auf der Zapier-Seite <UiPath path="integrations.reconnect" /> und fügen Sie den neuen Schlüssel in die
  Zapier-Verbindung ein.
- **„… unter Einstellungen › Integrationen › Zapier übernehmen …“**: Die Person, die Zapier verbunden hat, hat den
  Arbeitsbereich verlassen. Wählen Sie <UiPath path="integrations.takeOver" />; der Schlüssel bleibt derselbe.
- **Der Dialog zum Verbinden meldet, dass Ihre Instanz nicht erreichbar ist**: Zapier erreicht die öffentliche URL von
  ReputeCast nicht. Lesen Sie [Reverse Proxy und TLS](/de/self-hosting/reverse-proxy/).
- **Ein Trigger löst nie aus**: Prüfen Sie, ob der Zap eingeschaltet ist und der Webhook unter
  <UiPath path="nav.settings > settings.webhooks" /> steht. Fehlgeschlagene Zustellungen werden wiederholt und danach
  zum erneuten Abspielen aufbewahrt; lesen Sie [Webhooks empfangen](/de/developers/webhooks/).
