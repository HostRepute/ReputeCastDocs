Wenn Sie von MailerLite migrieren, verbinden Sie ReputeCast mit einem API-Token mit Ihrem MailerLite-Konto und importieren jede Gruppe in eine Liste in ReputeCast, mit den Feldern, Opt-in-Daten und Status ihrer Abonnenten. ReputeCast liest nur aus der API von MailerLite; in MailerLite ändert sich nichts.

## Bevor Sie beginnen

- Sie brauchen die Berechtigung `subscribers:import` (Inhaber, Admin und Bearbeiter haben sie).
- Erstellen Sie ein API-Token in MailerLite. Öffnen Sie in MailerLite **Integrations**, wählen Sie **MailerLite API** und klicken Sie auf **Generate new token**. Kopieren Sie es sofort: MailerLite zeigt es nur einmal. Ein Token gehört der Person, die es erstellt hat, und funktioniert nicht mehr, wenn diese Person aus dem Konto entfernt wird. Quelle: [MailerLite developers, Getting started](https://developers.mailerlite.com/getting-started) (geprüft im Oktober 2026).
- Der Import liest die API von MailerLite unter `connect.mailerlite.com`. Konten in MailerLite Classic nutzen eine ältere API, die der Import nicht unterstützt; exportieren Sie dort eine CSV-Datei und [importieren Sie die Datei](/de/audience/import/) stattdessen.
- Lesen Sie [wie eine Migration die Einwilligung übernimmt](/de/migrate/overview/), wenn dies Ihr erster Import ist.

## Ihre MailerLite-Gruppen importieren

<Steps>

1. Öffnen Sie <UiPath path="shell.importContacts" /> und wählen Sie **MailerLite**. Der Assistent verlinkt auf die API-Seite von MailerLite, falls Sie noch ein Token brauchen.

2. Fügen Sie das Token ein und wählen Sie <UiPath path="imports.connect" />. Der Assistent listet Ihre Gruppen mit der Anzahl abonnierter, abgemeldeter, bereinigter (Bounce) und ausstehender Kontakte.

3. Setzen Sie Häkchen bei den Gruppen, die Sie importieren möchten, und wählen Sie für jede die Liste in ReputeCast, in die sie geht. Lassen Sie das Abrufen der Sperren von Ihren Versandanbietern eingeschaltet und gehen Sie dann weiter zur Feldzuordnung.

4. Ordnen Sie die Felder zu. `email` ist erforderlich; Felder aus MailerLite wie `name` und `last_name` werden über Namen und Beispielwerte zugeordnet, und für den Rest werden neue eigene Felder angelegt.

5. Prüfen Sie im Schritt zur Einwilligung, was aus jedem Status wird (siehe nächster Abschnitt). Opt-in-Datum und IP aus MailerLite werden als Einwilligungsnachweis übernommen, sofern Sie nicht <UiPath path="imports.repermission" /> wählen.

6. Starten Sie die Vorschau und dann den Import.

</Steps>

## Was aus MailerLite umzieht

- **Gruppen** werden zu den Listen in ReputeCast, die Sie gewählt haben. Abonnenten, die in keiner Gruppe sind, werden nicht gelesen: Fügen Sie sie vor dem Import in MailerLite einer Gruppe hinzu oder exportieren Sie sie als CSV-Datei.
- **Felder** werden zu Kontaktfeldern.
- **Opt-in-Nachweis:** Opt-in-Datum und IP-Adresse werden als Einwilligungsnachweis gespeichert, und das Abonnementdatum wird zum Erstellungsdatum des Kontakts.

| Status in MailerLite                | Wird in ReputeCast                                                                                   |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `active`                            | Abonniert · bestätigt, mit Opt-in-Datum und IP als Nachweis (oder ausstehend oder Überspringen)      |
| `unconfirmed`                       | Abonniert · ausstehend, mit einer Re-Permission-E-Mail (oder Überspringen)                           |
| `bounced`                           | Gesperrt · Hard Bounce, alle Streams (fixiert)                                                       |
| `junk`                              | Gesperrt · Beschwerde, alle Streams (fixiert)                                                        |
| `unsubscribed` oder jeder andere Status | Gesperrt · abgemeldet: kein Massenversand und keine Automationen, System-E-Mails erlaubt (fixiert) |

Neue Sperren behalten den Grund aus MailerLite, etwa „in MailerLite als cleaned markiert“ für einen Abonnenten mit Bounce. Sind die Zeilen drin, überträgt der Import alle davon, einschließlich Abmeldungen, an jeden verbundenen Versandanbieter, dessen Sperrliste neue Einträge annimmt; danach überträgt die reguläre [Sperrlisten-Synchronisierung](/de/providers/events-and-sync/) nur Hard Bounces und Beschwerden, die für alle E-Mails gelten.

### Was in MailerLite bleibt

Kampagnen und ihre Berichte, Automationen, Segmente, Formulare, Landingpages und Vorlagen werden nicht importiert. Bauen Sie sie mit [Segmenten](/de/audience/segments/), [Automationen](/de/automations/overview/), [Anmeldeformularen](/de/forms/signup-forms/) und dem [Editor](/de/campaigns/composer/) neu auf.

## Rate-Limits

Die API von MailerLite erlaubt 120 Anfragen pro Minute und antwortet darüber mit 429 Too Many Attempts und einem Header `Retry-After`. Quelle: [MailerLite developers, Getting started](https://developers.mailerlite.com/getting-started) (geprüft im Oktober 2026). ReputeCast liest 1.000 Abonnenten je Anfrage, immer nur eine Anfrage, wartet `Retry-After` ab, wenn MailerLite darum bittet, und pausiert den Import, wenn die Quelle weiter ablehnt:

<LimitsTable area="imports" />

<UiPath path="imports.slowDown" /> sendet höchstens 3 Anfragen pro Sekunde, was immer noch über dem Durchschnitt von 2 pro Sekunde bei MailerLite liegt; ein großes Konto kann daher ab und zu pausieren. Jede Pause wird von selbst fortgesetzt.

## Prüfen, ob es funktioniert hat

- Die Zusammenfassung zeigt, wie viele Kontakte importiert, zusammengeführt, gesperrt, als ausstehend belassen und übersprungen wurden und wie viele jede Liste jetzt hat. <UiPath path="imports.downloadReport" /> listet jede Zeile mit dem, was mit ihr geschehen ist.
- Öffnen Sie <UiPath path="nav.audience > audience.tabSuppressions" />: Abonnenten mit Bounce, Junk oder Abmeldung stehen dort mit dem Grund aus MailerLite.

## Fehlerbehebung

- **„MailerLite hat den API-Schlüssel abgelehnt“**: Das Token wurde gelöscht, oder die Person, die es erstellt hat, hat das Konto verlassen. Generieren Sie ein neues Token und fügen Sie es ein.
- **Eine Gruppe fehlt**: Der Import listet jede Gruppe des Kontos, zu dem das Token gehört. Prüfen Sie, ob Sie das Token im richtigen MailerLite-Konto erstellt haben.
- **Abonnenten fehlen im Import**: Sie sind in keiner Gruppe, oder ihr Status hat sie zu einer Sperre gemacht. Unbestätigte Abonnenten kommen als ausstehend an und erhalten keine Marketing-E-Mails, bis sie bestätigen.
- **„MailerLite drosselt unsere Anfragen (429); pausiert“**: Eine andere Integration nutzt das Limit desselben Kontos. Warten Sie auf die automatische Fortsetzung oder wählen Sie <UiPath path="imports.resumeNow" />.
