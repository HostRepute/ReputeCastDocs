## New in 1.6.0

ReputeCast 1.6.0 adds a dark theme and the first batch of what a look at other newsletter platforms found missing:
the new DMARC standard and Microsoft's sender rules, allowed IP addresses for API keys, smarter signup forms, share
buttons on posts, paid-member triggers, richer campaign reports and a sending summary by email. Read the
[release notes](/reference/release-notes/).
