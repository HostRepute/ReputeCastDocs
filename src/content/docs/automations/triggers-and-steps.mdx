<UiPath path="automations.panels.reentry" />: <UiPath path="automations.panels.oncePerContact" /> [default] lets a
contact through the flow one time, and <UiPath path="automations.panels.everyTime" /> lets them enter again.
Exceptions:

- A contact enters <UiPath path="scoring.trigger.kind" /> flows at most once in the set number of days, and
  enters <UiPath path="grow.trigger.kind" /> flows once per milestone.
- An <UiPath path="automations.graph.kindAbandonedCheckout" /> flow starts for every new abandoned checkout; the
  7-day rule above limits it.
- With <UiPath path="pollTrigger.onChange" />, a changed answer starts the flow again whatever the re-entry setting.

## Goal and exit

The palette's <UiPath path="automations.panels.goalOrExit" /> item adds either; <UiPath path="automations.panels.endsAs" />
switches between them.

| Step                                   | What it does                                                                                                                                                                                                                                                                             | Options (defaults in brackets)                                                                                                                                                                                         |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <UiPath path="automations.graph.typeGoal" /> | Ends the flow for contacts who meet it and counts toward the goal rate in the list. A contact who meets the goal anywhere in the flow jumps to it and finishes; one who arrives without meeting it goes on to the next step, if there is one. A goal leads to at most one step. | <UiPath path="automations.panels.endGoal" />; <UiPath path="automations.panels.goalName" />; <UiPath path="automations.panels.reachedWhen" />: a condition [<UiPath path="automations.panels.condClicked" />], or <UiPath path="automations.panels.condReaching" /> (met on arrival). |

A path that ends without a goal or exit also ends the flow for the contact who reaches its last step.

## Webhook step calls

Each call sends this JSON body with `Content-Type: application/json`, `User-Agent: ReputeCast-Webhooks/1.0` and
`X-ReputeCast-Event: automation.step`. The step's name is its <UiPath path="automations.panels.name" />, or the
URL's host when it has none.

```json title="Webhook step request body"
{
  "type": "automation.step",
  "id": "01a16a2e-5c7e-7b51-9f0e-3d2c1b0a9e8f",
  "occurredAt": "2026-10-22T09:14:03Z",
  "automation": { "id": "01a1637b-8042-7b3b-ae2f-a664344e716b", "name": "Onboarding", "version": 7 },
  "step": { "id": "n7", "name": "Sync to CRM" },
  "contact": {
    "id": "01a1637a-91c4-7d2e-8b0f-5a6e3c2d1b0a",
    "email": "ana@example.com",
    "firstName": "Ana",
    "lastName": "Silva",
    "tags": ["trial"],
    "fields": { "plan": "team" }
  }
}
```

| Rule        | Value                                                                                                                                                                                                                                                   |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Signature   | With a signing secret set, `X-ReputeCast-Signature: t=<Unix seconds>,v1=<signature>`, where the signature is the lowercase hex HMAC-SHA256 of `<t>.<raw body>`, keyed with the secret. Endpoints from <UiPath path="nav.settings > settings.webhooks" /> sign differently: see [receive webhooks](/developers/webhooks/). |
| Success     | Any 2xx response.                                                                                                                                                                                                                                       |
| Timeouts    | 5 seconds to connect, 10 seconds for the response headers, 15 seconds in total. At most 3 redirects.                                                                                                                                                  |
| Retries     | Network errors, 429 and 5xx responses are retried: 3 attempts in total, about 30 seconds and 2 minutes apart. Other responses are not retried.                                                                                                         |
| Failure     | The contact moves on anyway. The call is in the step's <UiPath path="automations.panels.deliveryLog" />, and the list shows <UiPath path="automations.stepFailing" /> until a call works again.                                                       |
| Addresses   | Public addresses only. ReputeCast checks the address it actually connects to, after DNS and on every redirect, so private, loopback, link-local and internal addresses are refused.                                                                   |
| Log         | Calls are kept for 90 days; the delivery log shows the latest 30.                                                                                                                                                                                       |

## Flow rules

These problems block publishing; the editor lists them under <UiPath path="automations.flow.beforePublish" />.

- A flow has one trigger, and nothing leads into it.
- Every step is connected to the trigger, and no connection leads back to an earlier step.
- Each path out of a branch or A/B split is connected exactly once. Other steps lead to at most one step; an exit
  leads to none.
- Every step is set up: a picked email with a subject, a list that still exists, a valid tag, event name or URL, a
  delay above zero, split weights that add up to 100%.
- A flow has at most 200 steps and 400 connections.

A webinar landing page can create a draft reminder flow for you: a Date field trigger on the field its registration
form writes, an email the day before at the session's time, a 23-hour delay and a second email an hour before. See
[build landing and sales pages](/forms/landing-pages/).
