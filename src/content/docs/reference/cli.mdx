This page lists every command of the `reputecast` CLI, the single binary that runs the server, the workers and the maintenance tasks.

In the Docker image, run a command inside the app container: `docker compose exec app /usr/local/bin/reputecast <command>`. Configuration comes from the same sources as `reputecast serve` (see [configure ReputeCast](/self-hosting/configuration/)), so pass `--config` or the `REPUTECAST_*` variables the server uses.

<CliReference />

## Exit codes

| Code | Meaning                                                                                                                                                                                                                                                                         |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `0`  | The command succeeded.                                                                                                                                                                                                                                                          |
| `1`  | The command failed: a database, network or configuration error, an unknown flag or a wrong number of arguments.                                                                                                                                                                |
| `2`  | ReputeCast refused the request before doing anything: `user reset-2fa` without `--reason`, a `--password` that breaks the password policy, an unknown `seed --sample`, or `seed` (without `--force`) or `demo send` outside `REPUTECAST_ENV=development`. |

Every error is printed to standard error as `Error: <message>`.
