This page lists the ReputeCast limits and defaults the guides refer to, one table per area. **How to change** names the setting, configuration key or API field that changes a value, with its allowed range; _Fixed_ means the value is set in code.

App settings apply to one workspace, except those under <UiPath path="shell.userMenuInstanceAdmin" />, which apply to the whole instance like configuration keys (see the [configuration reference](/reference/configuration/)). The values that protect a running send are explained in [monitor a send and auto-pause](/campaigns/live-monitor/), and API rate limits in [rate limits](/developers/api-rate-limits/).
