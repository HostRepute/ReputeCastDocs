What changed in each ReputeCast release, newest first. Every release on
[GitHub](https://github.com/hostrepute/reputecast/releases) has the binary for Linux, macOS and Windows (amd64 and
arm64) with a `checksums.txt`, and the Docker image `ghcr.io/hostrepute/reputecast:<tag>` (linux/amd64 and
linux/arm64). To move to a new release, follow [upgrade ReputeCast](/self-hosting/upgrades/).

## 1.0.1

24 October 2026 · [Release on GitHub](https://github.com/hostrepute/reputecast/releases/tag/v1.0.1) · image
`ghcr.io/hostrepute/reputecast:v1.0.1`

**Security**

- An API request that failed on an unexpected error answered `500` with the error's own text, which could include SQL
  or internal host names. It now answers with the code `internal_error` and a reference in `meta.reference` (for
  example `err_7KQ2M4XA`), and the server logs the error under that reference with the request ID. Search the logs for
  the reference when someone reports one. Advisory
  [GHSA-9xjq-4j36-pcgm](https://github.com/HostRepute/ReputeCast/security/advisories/GHSA-9xjq-4j36-pcgm).

**Fixes**

- A notification list cursor beyond 2³¹ answered `500`; it is now refused with `422`.
- The adapter SDK trims trailing slashes from URLs in one pass instead of with a backtracking regular expression.

**Upgrading.** This release has no new database migrations. With Docker Compose, run
`docker compose pull && docker compose up -d`; with the binary, replace it and run `reputecast migrate up`.

## 1.0.0

24 October 2026 · [Release on GitHub](https://github.com/hostrepute/reputecast/releases/tag/v1.0.0) · image
`ghcr.io/hostrepute/reputecast:v1.0.0`

The first stable release. Every feature is free, with no paid edition and no seat or workspace limit.

- **[Send Readiness](/campaigns/send-readiness/)**: a verdict before every send (Ready, Ready with warnings, Blocked)
  from sender reputation, authentication, content, links, compliance, audience and routing checks, each with its
  evidence and fix.
- **[Guarded sending](/campaigns/live-monitor/)**: live results per mailbox provider and sending provider, and an
  automatic pause when bounces, complaints or a provider outage cross your thresholds.
- **[Sending providers](/providers/choose/)**: built-in adapters for Amazon SES, Mailgun, SendGrid, Postmark, Resend,
  SparkPost, Mailjet, Brevo, Azure Communication Services, Postal and SMTP, a [generic HTTP adapter and an adapter
  SDK](/adapters/overview/), with routing, failover, warm-up and one shared suppression list.
- **[Composer](/campaigns/composer/)** on GrapesJS and MJML, with Liquid personalization, previews, A/B variants and
  inline deliverability warnings; **[reports](/campaigns/reports/)** that separate human opens from machine opens.
- **[Audience](/audience/contacts/)**: contacts, segments, list health and a sunset policy;
  [imports](/migrate/overview/) from Brevo, Mailchimp, MailerLite, listmonk, Keila, CSV and XLSX that keep
  suppressions.
- **[Automations](/automations/overview/)** with triggers, delays, branches, A/B splits, webhooks and goals.
- **[Signup forms and public pages](/forms/signup-forms/)**: double opt-in, preference center, unsubscribe page and a
  public archive with RSS.
- **[Deliverability](/deliverability/overview/)**: domain, IP and provider health, blocklists, DMARC reports and
  incidents, with more data when you connect HostRepute.
- **[Teams and access](/team/roles-and-permissions/)**: workspaces, built-in and custom roles, send approvals,
  passkeys and two-factor, social sign-in, OIDC single sign-on and an audit log.
- **[API, webhooks and MCP](/developers/overview/)**: the REST API with its OpenAPI document, API keys, signed
  outgoing webhooks and an MCP server for AI agents.
- **[Self-hosting](/self-hosting/requirements/)**: one Docker image or a single binary with PostgreSQL 16, 17 or 18
  as its only dependency.
