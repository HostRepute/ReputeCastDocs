This page is the MCP tools list of the ReputeCast [MCP](/reference/glossary/#mcp) server, with its resources and prompts.

The server listens at `<public URL>/mcp` (Streamable HTTP). An [MCP agent](/reference/glossary/#mcp-agent) authenticates with `Authorization: Bearer rc_agent_…`; create agents in <UiPath path="nav.settings > settings.keys" />. [Connect AI agents with MCP](/developers/mcp/) shows client setup.

- **Permission**: what the agent needs to call the tool. Without it, the call is denied and ReputeCast records a proposal for a member who holds the permission. An agent never does more than the member who created it can do.
- **Effect**: _Reads data_ changes nothing. _Changes data_ acts at once. _Proposes; a person approves_ creates a request that a member confirms in ReputeCast; nothing happens until then.
- Every tool call, allowed, denied or failed, is written to the [audit log](/team/audit-log/) with the agent's name.
- **Reports**: `get_campaign_report` returns the same report the app shows, with human, privacy-protected and scanner opens apart and complaints only where reported; `share_campaign_report` makes a read-only link that always expires. See [read campaign reports](/campaigns/reports/).
