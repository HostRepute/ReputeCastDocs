ReputeCast's AI email writing assistant suggests subject lines, rewrites text, translates
[language versions](/campaigns/languages/), writes alt text and drafts segments with a model you connect yourself:
Anthropic, OpenAI, Google Gemini, Azure OpenAI or an OpenAI-compatible server on your own network. The assistant is
off until you connect a model, the provider bills your own account, and nothing changes in an email until a person
accepts the suggestion. Since 1.7.0 the same model also suggests a [brand voice](/campaigns/brand-voice/) from your
sent campaigns, [drafts an email or a flow from a brief](/integrations/ai-drafts/) and runs the
[AI agent](/integrations/ai-agent/).

## Before you begin

- Connecting, changing or disconnecting the model needs `integrations:manage`, a
  [sensitive permission](/reference/glossary/#sensitive-permission) that only people can hold (Owner and Admin have
  it). Members with `integrations:view` can open the page and read usage and the activity log.
- Asking for suggestions needs `ai:use`. Owner, Admin and Editor hold it; a Viewer can read kept report summaries but
  can't ask for suggestions. API keys and [MCP agents](/developers/mcp/) can't hold `ai:use`. Each feature also needs
  the permission for what it changes, for example `campaigns:edit` in the composer or `segments:edit` for segment
  drafts. Read [Permissions and roles](/reference/permissions/).
- Have an API key from the model provider, or the address of your own server. For a model that isn't on ReputeCast's
  price list, also have its input and output prices per million tokens (since 1.7.0).
- A workspace has one model at a time. To switch provider, disconnect the current one first.

## Connect a model

<Steps>

1. Open <UiPath path="nav.settings > settings.integrations" /> and find the <UiPath path="integrations.groupAi" />
   group, or open <UiPath path="nav.settings > settings.integrations > ai.title" /> directly. Choose
   <UiPath path="ai.connectModel" />.

2. Pick the provider and fill in its fields:

   - **Anthropic, OpenAI, Google Gemini**: the API key and the model.
   - **Azure OpenAI**: the endpoint (HTTPS, for example `https://acme.openai.azure.com`), the deployment name, the API
     key, an optional API version and the model the deployment runs (used for prices). Your data stays in the region
     of your Azure resource.
   - **OpenAI-compatible** (Ollama, vLLM, LM Studio and others): the server address including `/v1`, an optional name
     and, if the server needs one, an API key.

   The model list comes from ReputeCast's price list first, then from the provider once the key (or the server
   address) is filled in. If your model isn't listed, choose **Type a model name…**.

   The key is write-only: it's stored encrypted and never shown again, not even to you. A saved key goes only to the
   address it was entered for: since 1.5.0, when you change an Azure OpenAI endpoint or an OpenAI-compatible server's
   address and leave the key blank, the dialog asks you to paste the key again.

3. Set the monthly cap. For hosted providers the dialog starts at $25 a month, using ReputeCast's prices per million
   tokens (you can edit the prices). An OpenAI-compatible server starts with a token cap of 20,000,000 tokens a month.
   After connecting, you can switch to dollars, tokens or no cap.

   Since 1.7.0, both prices must be set before you connect, whatever the cap. A model on ReputeCast's price list fills
   them in; for any other model, such as one on an OpenAI-compatible server, type both. Enter 0 for a model that costs
   nothing. Without both prices, ReputeCast can't bound what a request costs and sends nothing, not even the test.

4. Choose **Connect**. ReputeCast first sends a fixed test prompt with no workspace content ("Reply with the word
   Ready.") and saves nothing if the test fails.

   Since 1.7.0, every test uses tokens and counts toward the monthly cap: the test when you connect, the one when you
   replace a key, and each <UiPath path="ai.testConnection" />. Before the first connection, tests share a monthly cap
   of their own (see [cap, usage and the activity log](#cap-usage-and-the-activity-log)).

</Steps>

### Models on your own network

An OpenAI-compatible server on a private or loopback address (such as `http://ollama.acme.internal:11434/v1`) is
refused with "Can't connect to a private address" until an operator sets
[`providers.allow_private_networks`](/reference/configuration/) to `true`
(`REPUTECAST_PROVIDERS__ALLOW_PRIVATE_NETWORKS=true`). Host names ending in `.internal` or `.localhost` count as
private. Link-local and cloud metadata addresses are always refused. Read
[Security and hardening](/self-hosting/security/).

## What the assistant does

Each feature has its own switch under <UiPath path="ai.featuresTitle" />; all nine start on, including the two added in
1.7.0.

| Feature | Where you find it | What you get |
|---|---|---|
| Subject ideas | **Ideas** next to the subject in the composer, or **Assist** › **Subject ideas** | Five subjects, each with the subject checks; **Use this** applies one |
| Rewrite, shorten and tone | The text toolbar: **Shorten**, **Friendlier**, **More formal**, **More direct**, **With an instruction…** | The rewritten text as a change against the original |
| Translate a language version | **Translate &lt;language&gt; with AI** in the composer's language menu, the Add language dialog or the compare view | A side-by-side translation to accept block by block or all at once |
| Alt text | **Suggest alt text** in an image's settings, and in the accessibility panel | A description with checks; "Decorative image" stays your choice |
| Accessibility fixes | **Suggest a fix** in the accessibility panel | Clearer link text |
| Describe the segment | The segment builder's **Describe the segment** card, then **Draft** | Conditions marked Added and Removed, with the live count |
| Report summaries | **Summarize results** on a campaign report | A summary to keep, edit or discard |
| <UiPath path="ai.featureBrandVoice" /> | <UiPath path="brandkit.voice.learn" /> on the <UiPath path="brandkit.voice.title" /> card of the brand kit | A suggested voice to edit, then save or reject: see [set your brand voice](/campaigns/brand-voice/) |
| <UiPath path="ai.featureDraft" /> | <UiPath path="ai.draft.title" /> in <UiPath path="campaigns.newCampaign" /> and in the composer's <UiPath path="ai.suggest.assist" /> menu; <UiPath path="ai.automationDraft.title" /> in <UiPath path="automations.newAutomation" /> | A whole email, or a flow that starts when someone joins a list, as a proposal to accept: see [draft from a brief](/integrations/ai-drafts/) |

On a phone, the composer's **Assist** menu is the sparkle in its top bar, and its cards show under the email. Alt text
and accessibility fixes say <UiPath path="ai.suggest.largerScreen" /> there: they open in the inspector, which larger
screens have.

The [AI agent](/integrations/ai-agent/) has no switch among these. Someone with `integrations:manage` turns it on under
<UiPath path="ai.agent.settings" />, below the features, where <UiPath path="ai.agent.testTools" /> checks that the
model calls tools. A failed check stops the agent's model work until a test passes or the connection changes.
Available since 1.7.0.

Assistants outside ReputeCast, such as ChatGPT or Claude, can [propose drafts through an external
connection](/developers/mcp-connections/). They bring their own model and never use this connection or its cap.

### Choose the brand voice

Since 1.7.0, subject ideas, rewrites and drafts from a brief follow the workspace's saved
[brand voice](/campaigns/brand-voice/) as style guidance. Pick the voice for a request under
<UiPath path="brandkit.voice.voiceSelection" />, at the top of the composer's <UiPath path="ai.suggest.assist" /> menu
and in the draft dialogs: <UiPath path="brandkit.voice.latest" /> (the default), <UiPath path="brandkit.voice.none" />
or an earlier revision. Until someone saves a voice, the requests carry none.

### Nothing changes without you

- A request starts only when someone clicks. The model's answer is a suggestion: **Accept**, **Edit** (opens it in the
  block first), **Reject** or **Try again**. For subject ideas you choose **Use this**; report summaries offer **Keep**
  and **Discard**.
- Accepted rewrites and alt text are saved through the composer like any edit, so they appear in
  [version history](/campaigns/composer/) and can be undone.
- Personalization tokens and links the model changed are restored from your original, and the card says how many.
- A suggestion can be decided only by the person who asked for it, within 24 hours.
- A translation accepted in full is marked "AI · not reviewed" until someone marks it reviewed or edits it.
- Drafts that an AI agent writes through the [MCP server](/developers/mcp/) are compiled, checked and versioned like
  the composer's saves, and never cancel an approval.
- Since 1.7.0, a draft from a brief, a learned brand voice and the AI agent's drafts are proposals too: nothing is saved
  until a person accepts, saves or keeps one, and keeping a draft never sends, schedules or publishes it.

The assistant doesn't look at sender reputation. Questions about blocklists, DMARC or why mail goes to spam send
nothing to the model; ReputeCast points you to [Deliverability](/deliverability/overview/) instead.

## What leaves your instance

Only what a person is working on, only when they ask, and only for the features that are on:

- **Subject ideas and translation**: the email's text (without images), subject, preheader and language. Since 1.7.0,
  subject ideas also send the [brand voice](#choose-the-brand-voice) chosen for the request.
- **Rewrite**: the selected paragraph and your instruction, and since 1.7.0 the chosen brand voice.
- **Alt text**: the image (resized to 1,024 px wide), its file name and the text around it. The model must read
  images; with a text-only model, alt text stays off.
- **Accessibility fixes**: the link text, its address and the sentence around it.
- **Segment drafts**: your description, the segment builder's field names, operators and option names (lists, tags,
  tiers) and the current conditions.
- **Report summaries**: totals and rates, the top three links, mailbox provider rates and unsubscribe reasons.
- **Brand voice learning**: the unrendered text of the sent campaigns you pick, with Liquid tokens as written.
- **Drafts from a brief**: your brief, the editorial text of the template or draft you start from, and the chosen
  brand voice. Links, images and Liquid tokens travel as placeholders; link destinations and the compliance footer
  stay on your instance. See [what a draft shares](/integrations/ai-drafts/#what-leaves-your-instance).
- **The AI agent**: the brief and the context you add to it, as its brief page lists them. See
  [draft with the AI agent](/integrations/ai-agent/).

Since 1.7.0, before brand voice learning, a draft from a brief or an agent run shares workspace content,
<UiPath path="ai.draft.sharingTitle" /> lists what goes to the model, and nothing is sent until you choose
<UiPath path="ai.draft.sharingConfirm" />. ReputeCast refuses the request, before sending anything, when the content
looks like it holds personal data or credentials.

Never sent: contacts, addresses, names, field values, recipient lists, keys or credentials. Liquid tokens go as written
(a preview "as a contact" is never sent), and nothing from the assistant goes to HostRepute.

## Cap, usage and the activity log

Usage is the token count the provider reports times the prices on the page, added up from the 1st of the month in the
workspace time zone. Since 1.7.0 it includes connection tests and the AI agent's requests.

<LimitsTable area="ai" />

- At 80% of the cap, members with `integrations:manage` get a notification (in the app and by email). At 100% the
  assistant pauses until the 1st; editing, sending and reports carry on as usual. Raising the cap resumes it.
- <UiPath path="ai.byFeature" /> lists the nine features, then <UiPath path="ai.agent.title" /> for the agent's requests
  and <UiPath path="ai.testConnection" /> for connection tests and tool-calling tests. Available since 1.7.0.
- The **AI activity log** keeps who asked, when, which feature, on what, the model, tokens, cost and the outcome for
  90 days, without the text that was sent or returned.
- Since 1.7.0 the log also lists connection tests and the agent's requests, and shows
  <UiPath path="ai.usageUnknown" /> instead of the tokens when the provider didn't report them.
- Connecting, changing the model or key, the cap, prices and feature switches are recorded in the
  [audit log](/team/audit-log/). Single suggestions are not. Since 1.7.0, drafts from a brief, agent runs and the agent
  settings, confirmed sharing reviews and reconciliations are recorded too, without their content.

### Reserved requests and unknown usage

Since 1.7.0, ReputeCast reserves what a request can cost before it sends it: its input and the longest answer it
allows, at the configured prices. The request goes out only when what is left of the monthly cap covers it on top of
the requests in progress. When the provider answers, the reservation becomes the measured usage.
<UiPath path="ai.usageTitle" /> shows what is reserved: the cap meter counts it, the measured usage doesn't.

When the provider doesn't return token counts it can trust, for example after a timeout, a server error or an answer
that can't be read, or when a request is cut off on its way, ReputeCast keeps the whole reservation and never repeats
the request on its own. The <UiPath path="ai.logTitle" /> shows <UiPath path="ai.usageUnknown" />,
<UiPath path="ai.usageTitle" /> says how many requests have unknown usage, and an [agent run](/integrations/ai-agent/)
with one pauses. The reservation stays held, also after the 1st, until someone with `integrations:manage`
reconciles it:

<Steps>

1. Under <UiPath path="ai.holdsTitle" /> on this page, find the request by its model, time and ID. Only people with
   `integrations:manage` see the card, and only while a reservation is held.

2. Look up the request's input and output tokens in your model provider's usage records.

3. Choose <UiPath path="ai.reconcile" />, enter <UiPath path="ai.reconcileInput" /> and
   <UiPath path="ai.reconcileOutput" />, confirm that you checked them with the provider, and choose
   <UiPath path="ai.reconcile" /> again. Enter 0 only when the provider confirms it didn't charge for the request.

</Steps>

Reconciling replaces the reservation with the token counts you enter, at the prices the request was reserved with. It
doesn't repeat the request or recover its answer. It works only once the request can't still be running (see the
table above); until then the dialog says from when. Each reconciliation is in the audit log as `ai.usage_reconciled`.

## Check that it worked

- The page shows **Connected**, the model and a **Last test** time.
- In the composer, the **Assist** menu lists the features you switched on.

## Troubleshooting

- **"Error · key rejected"**: the provider refused the key. Every feature stops until you choose **Replace key** or a
  **Test connection** passes.
- **Connecting fails with a validation error while all nine features are ticked**: in 1.7.0 the server accepts at most
  eight features when you connect. Untick one in the dialog, connect, then switch it on under
  <UiPath path="ai.featuresTitle" />.
- **"Can't connect to a private address"**: see [Models on your own network](#models-on-your-own-network).
- **"The address changed: paste the API key again"**: ReputeCast doesn't send a saved key to a new address. Paste the
  key with the new endpoint or server address.
- **Azure: the wrong deployment after Change model**: changing the model also sets the deployment name to the model
  you picked. Choose **Type a model name…** and enter the deployment name.
- **Alt text stays off**: the model doesn't read images. Pick a model that does.
- **"This month's cap is reached"**: raise the cap under **Monthly cap** › **Edit**, or wait for the 1st.
- **The provider's rate limit**: the card counts down ("Try again in N s"); nothing in the email changes.
- **"Cost unknown. An integration manager must configure both model prices before another request can be sent."**: the
  model has no prices. Set both under <UiPath path="ai.pricesTitle" /> › <UiPath path="common.edit" />, 0 for a model
  that costs nothing. After the upgrade to 1.7.0, a connection whose two prices were 0 and didn't come from
  ReputeCast's price list needs this once.
- **"The remaining monthly budget cannot cover this request and requests already in flight."**: wait for the requests
  in progress to finish, reconcile any [reserved requests](#reserved-requests-and-unknown-usage), or raise the cap.
- **A request shows <UiPath path="ai.usageUnknown" />**: the provider didn't report its usage. Look it up in the
  provider's records and [reconcile it](#reserved-requests-and-unknown-usage).
- **"Reconciliation available after …"** in the dialog, or `ai_reconcile_wait` from the API: the request may still be
  running. Reconcile it after the time shown.
- **<UiPath path="ai.agent.capabilityFailed" />**: the model didn't call the test tool as asked, so the agent can't use
  it. Use a model that supports tool calling, then choose <UiPath path="ai.agent.testTools" /> again.
